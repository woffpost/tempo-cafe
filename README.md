# Tempo Café — Specialty Coffee Shop

A warm, inviting landing page for an independent specialty coffee shop. Tabbed menu, loyalty programme, order-ahead form, and 3 branch locations.

## Features

- **Tabbed menu** — espresso drinks, filter coffee, food — tab switching with no page reload
- **Order ahead form** — name, location, time, order note → success confirmation
- **Loyalty card** — stamp card UI with progress tracker
- **Barista story** — craft and sourcing narrative section
- **3 locations** — branch cards with address, hours, and directions link
- **Mobile nav** — hamburger menu with smooth scroll links

## Tech Stack

- [Next.js 16](https://nextjs.org/) — App Router
- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) — icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
